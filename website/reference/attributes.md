# Attributes

Every attribute of Prism, with each of its parameters. The mapping attributes live in `Prism\Orm\Mapping` and are written with the `Prism\` alias (`use Prism\Orm\Mapping as Prism;`); the others are named with their namespace.

This page is checked against the code: a parameter added to an attribute fails the build until it is documented here.

## Entities

### `#[Entity]`

Makes a class an entity. Class attribute. See [Mapping entities](/guide/mapping#entities-and-tables).

| Parameter | Default | Description |
| --- | --- | --- |
| `repositoryClass` | `null` | The class returned by `getRepository()`; it extends `EntityRepository`. `null`: `EntityRepository` |
| `trackingPolicy` | `TrackingPolicy::Implicit` | `Implicit`: every managed entity is compared at flush. `Explicit`: only the entities passed to `persist()` since the last flush |
| `readOnly` | `false` | The entity is never compared at flush: it is inserted and deleted, never updated |

### `#[Table]`

The table of the entity. Class attribute.

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | `null` | The table name. `null`: the class name in snake case (`OrderLine` → `order_line`) |
| `options` | `[]` | MySQL and MariaDB table options: `engine`, `charset`, `collation`, `comment`. Any other key is refused |

## Identifiers

### `#[Id]`

Marks the identifier property. Each entity has exactly one. No parameter.

### `#[GeneratedValue]`

Lets the identifier be generated. Property attribute, next to `#[Id]`.

| Parameter | Default | Description |
| --- | --- | --- |
| `strategy` | `GenerationStrategy::Auto` | `Auto`: `Identity` under MySQL, MariaDB and SQLite, `Sequence` under PostgreSQL. `Identity`: auto-increment column. `Sequence`: database sequence. `UuidV7`: generated by Prism before the `INSERT`, on a `uuid` column |
| `sequenceName` | `null` | The sequence of `Auto` or `Sequence`. `null`: `<table>_id_seq` |

## Fields

### `#[Column]`

Stores a property in a column. Every `null` parameter is deduced from the PHP type. See [Columns and types](/guide/mapping#columns-and-types).

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | `null` | The column name. `null`: the property name in snake case |
| `type` | `null` | `string`, `text`, `integer`, `bigint`, `smallint`, `boolean`, `decimal`, `float`, `datetime_immutable`, `date_immutable`, `time_immutable`, `json`, `uuid`, `binary`, or a custom type. `null`: deduced from the PHP type |
| `length` | `null` | Length of a `string` or `binary` column. `null`: 255 for a `string` |
| `nullable` | `null` | `null`: deduced from the PHP type (`?string`). A value that contradicts the type is a mapping error |
| `unique` | `false` | A unique constraint on this column alone; per tenant on a `#[Tenanted]` entity, on live rows on a `#[SoftDeletable]` one |
| `precision` | `null` | Total number of digits of a `decimal`, from 1 to 65; required for a `decimal` |
| `scale` | `null` | Digits after the decimal point of a `decimal`, from 0 to 30, at most `precision`; required for a `decimal` |
| `enumType` | `null` | The backed enum of the property. `null`: read from the PHP type |
| `default` | `null` | The default value of the column in the database |
| `sensitive` | `false` | The value is written as `***` in the audit log |
| `insertable` | `true` | `false`: the column is left out of `INSERT` statements |
| `updatable` | `true` | `false`: the column is left out of `UPDATE` statements, for a column computed by the database |
| `fixed` | `false` | Fixed length: `CHAR` or `BINARY` instead of `VARCHAR` or `VARBINARY`; needs a `length` |
| `dimensions` | `null` | The dimension of a `vector` column, from 1 to 16,000; required for a `vector`. A vector of another size is refused before it is written. See [Vector search](/guide/vector-search#a-vector-field) |
| `lazy` | `null` | `true`: the field is not read with the entity, only on first access, for the whole batch. `null`: `true` for a `Prism\Orm\Vector\Vector` property, `false` otherwise; only a `Vector` can be lazy |

### `#[Version]`

Optimistic locking: the field is checked and incremented by each `UPDATE`, and a concurrent change throws `OptimisticLockException`. On an `int` or `\DateTimeImmutable` property, next to `#[Column]`. No parameter.

## Embeddables

### `#[Embeddable]`

Makes a class a value object stored in the columns of the entity that contains it. Class attribute; its properties carry `#[Column]`. No parameter.

### `#[Embedded]`

Stores an embeddable in the entity. Property attribute. A nullable embeddable is `null` when all its columns are `NULL`.

| Parameter | Default | Description |
| --- | --- | --- |
| `class` | `null` | The embeddable class. `null`: the property type |
| `columnPrefix` | `null` | `null`: the property name in snake case and `_` (`billing_address_`). `false`: no prefix. A string: that prefix |

## Indexes

### `#[Index]`

An index on one or more fields. Class attribute, repeatable. On a `#[Tenanted]` entity, `tenant_id` comes first.

| Parameter | Default | Description |
| --- | --- | --- |
| `fields` | | The fields indexed, in order: PHP properties, owning `ManyToOne` or `OneToOne` relations (their foreign key column), or `address.city` for a field of an embeddable |
| `name` | `null` | The index name. `null`: generated from a hash of the columns, stable from one diff to the next |
| `where` | `null` | Accepted, but not applied yet: the index covers every row, which makes it wider, never wrong. Partial indexes with a free condition are planned after 1.0 |

### `#[UniqueConstraint]`

A unique constraint on one or more fields. Class attribute, repeatable. On a `#[Tenanted]` entity, unique per tenant; on a `#[SoftDeletable]` entity, unique among the rows that are not deleted.

| Parameter | Default | Description |
| --- | --- | --- |
| `fields` | | The fields of the constraint: PHP properties or owning `ManyToOne` / `OneToOne` relations |
| `name` | `null` | The constraint name. `null`: generated, stable |
| `where` | `null` | Not supported yet: a unique constraint with a `where` is refused when the schema is built, since enforcing it without its condition would reject valid rows |

## Vector search

See [Vector search](/guide/vector-search). Not on MySQL, which has no vector type: these attributes are refused when the mapping is validated for it.

### `#[VectorIndex]`

An HNSW index on a `vector` field, used by `nearest()`, `hybridSearch()` and `distanceTo()`. Property attribute, next to `#[Column(dimensions: …)]`. On MariaDB, the column must be `NOT NULL`, and a table has one vector index at most.

| Parameter | Default | Description |
| --- | --- | --- |
| `distance` | `Distance::Cosine` | `Distance::Cosine`, `Distance::Euclidean`, or `Distance::InnerProduct` (PostgreSQL and SQLite only). Also the distance of `nearest()` on this field |
| `m` | `16` | Connections per node of the graph, from 2 to 100 |
| `efConstruction` | `64` | Search width while building the graph, from 4 to 1,000, at least `2 × m` |

### `#[FullTextIndex]`

A full-text index on text fields, searched by `hybridSearch()`. Class attribute, repeatable. `FULLTEXT` on MySQL and MariaDB, a GIN index on `to_tsvector()` on PostgreSQL, scored in PHP on SQLite.

| Parameter | Default | Description |
| --- | --- | --- |
| `fields` | | The `string` or `text` fields indexed |
| `language` | `'simple'` | The text search configuration of PostgreSQL: `english`, `french`, `simple` (no stemming)… Ignored by the other databases |
| `name` | `null` | The index name, and `HybridOptions::$fullTextIndex` when the entity has several. `null`: generated, stable |

### `#[EmbeddedVector]`

Keeps a `vector` field computed from text fields. Property attribute, next to `#[Column(dimensions: …)]`. Adds two columns without properties, `<column>_stale` and `<column>_model`. A change of a source field makes the vector stale at flush; after the commit, the stale rows go to the embedding scheduler. A stale vector is left out of `nearest()`. See [Keeping embeddings up to date](/guide/vector-search#keeping-embeddings-up-to-date).

| Parameter | Default | Description |
| --- | --- | --- |
| `source` | | The `string` or `text` field, or the list of fields, whose text is embedded, joined by a blank line |
| `model` | `'default'` | The name of the embedding provider, in the `EmbeddingProviderRegistry` (`prism.embeddings.providers` in Symfony); its dimension must be the one of the column |

## Relations

See [Relations](/guide/relations). In the tables below, `cascade` is a list of `Cascade::Persist`, `Cascade::Remove` and `Cascade::Detach`, and `fetch` is `Fetch::Lazy`, `Fetch::Eager` or `Fetch::ExtraLazy`.

### `#[ManyToOne]`

The owning side of a many-to-one relation: it holds the foreign key.

| Parameter | Default | Description |
| --- | --- | --- |
| `targetEntity` | `null` | The target class. `null`: the property type |
| `inversedBy` | `null` | The property of the target that holds the other side |
| `cascade` | `[]` | Operations propagated to the target |
| `fetch` | `Fetch::Lazy` | When the target loads |
| `joinColumn` | `null` | The foreign key column. `null`: `<property>_id` |
| `onDelete` | `OnDelete::Restrict` | What the database does when the target row is deleted: `Restrict`, `Cascade`, `SetNull`, `NoAction` |
| `batchSize` | `null` | Batch size of batch fetching, from 1 to 1000. `null`: the entity manager's, 100 by default |
| `batch` | `true` | `false`: no batch fetching for this relation |
| `foreignKey` | `null` | The foreign key constraint name. `null`: generated, stable |

### `#[OneToMany]`

The inverse side of a `ManyToOne`, as a `Collection`. It has no column.

| Parameter | Default | Description |
| --- | --- | --- |
| `targetEntity` | | The class of the elements; required |
| `mappedBy` | | The `ManyToOne` property of the target; required |
| `cascade` | `[]` | Operations propagated to the elements |
| `fetch` | `Fetch::Lazy` | `ExtraLazy`: `count()` runs a `COUNT` query without loading the elements |
| `orphanRemoval` | `false` | An element removed from the collection is deleted at the flush |
| `indexBy` | `null` | A field of the target whose values key the collection |
| `batchSize` | `null` | Batch size of batch fetching, from 1 to 1000 |
| `batch` | `true` | `false`: no batch fetching for this collection |

### `#[OneToOne]`

A one-to-one relation. The owning side holds a unique foreign key; the inverse side has `mappedBy` and no column.

| Parameter | Default | Description |
| --- | --- | --- |
| `targetEntity` | `null` | The target class. `null`: the property type |
| `mappedBy` | `null` | On the inverse side: the property of the target that owns the relation |
| `inversedBy` | `null` | On the owning side: the property of the target that holds the other side |
| `cascade` | `[]` | Operations propagated to the target |
| `fetch` | `Fetch::Lazy` | When the target loads; the inverse side is always loaded with its owner, in a batch |
| `joinColumn` | `null` | Owning side only: the foreign key column. `null`: `<property>_id` |
| `onDelete` | `OnDelete::Restrict` | Owning side only: what the database does when the target row is deleted |
| `orphanRemoval` | `false` | A target replaced or set to `null` is deleted at the flush |
| `batchSize` | `null` | Batch size of batch fetching, from 1 to 1000 |
| `batch` | `true` | `false`: no batch fetching for this relation |
| `foreignKey` | `null` | Owning side only: the foreign key constraint name |

### `#[ManyToMany]`

A many-to-many relation through a join table. The owning side, with `inversedBy` or without another side, writes the join table.

| Parameter | Default | Description |
| --- | --- | --- |
| `targetEntity` | | The class of the elements; required |
| `mappedBy` | `null` | On the inverse side: the property of the target that owns the relation |
| `inversedBy` | `null` | On the owning side: the property of the target that holds the other side |
| `cascade` | `[]` | Operations propagated to the elements |
| `fetch` | `Fetch::Lazy` | `ExtraLazy`: `count()` without loading the elements |
| `indexBy` | `null` | A field of the target whose values key the collection |
| `batchSize` | `null` | Batch size of batch fetching, from 1 to 1000 |
| `batch` | `true` | `false`: no batch fetching for this collection |

### `#[JoinTable]`

The join table of a `ManyToMany`, on the owning side.

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | `null` | The table name. `null`: `<owner table>_<target table>` |
| `joinColumn` | `null` | The column pointing to the owner. `null`: `<owner table>_id` |
| `inverseJoinColumn` | `null` | The column pointing to the target. `null`: `<target table>_id` |
| `onDelete` | `OnDelete::Cascade` | What the database does with the links when an owner or a target is deleted |

### `#[OrderBy]`

The order of a `OneToMany` or `ManyToMany` collection, applied in SQL and kept by batch fetching.

| Parameter | Default | Description |
| --- | --- | --- |
| `fields` | | Field → `Order::Asc` or `Order::Desc`, of `Prism\Dbal\Query\Order`, the enum `findBy()` and the query builder take too: `['position' => Order::Asc]` |

## Lifecycle

### `#[HasLifecycleCallbacks]`

Enables the lifecycle callbacks declared on the methods of the entity. Class attribute. No parameter.

### `#[PrePersist]`

The method runs before the `INSERT` of the entity, in the transaction of the flush; a change it makes is inserted. No parameter.

### `#[PostPersist]`

The method runs after the commit of the flush that inserted the entity. No parameter.

### `#[PreUpdate]`

The method runs before the `UPDATE` of the entity; a change it makes is included. No parameter.

### `#[PostUpdate]`

The method runs after the commit of the flush that updated the entity. No parameter.

### `#[PreRemove]`

The method runs when `remove()` is called, before the entity is scheduled for deletion. No parameter.

### `#[PostRemove]`

The method runs after the commit of the flush that deleted the entity. No parameter.

### `#[PostLoad]`

The method runs after the entity is loaded from the database, never when the identity map returns an entity already loaded. Since the constructor is not called, this is where derived state is computed. No parameter.

### `#[EntityListeners]`

Classes whose methods, carrying the lifecycle attributes above, receive the entity as first argument. Class attribute.

| Parameter | Default | Description |
| --- | --- | --- |
| `listeners` | | The listener classes. In Symfony, a class with `#[AsEntityListener]` is a service |

## Multi-tenancy and behaviors

### `#[Tenanted]`

Isolates the entity by tenant: a `tenant_id` column, filled and filtered by Prism. See [Multi-tenancy](/guide/multi-tenancy).

| Parameter | Default | Description |
| --- | --- | --- |
| `global` | `false` | Rows without a tenant are shared: every tenant reads them, only the system mode writes them |
| `column` | `null` | The name of the tenant column. `null`: `tenant_id` |
| `strictForeignKeys` | `false` | Composite foreign keys `(tenant_id, id)`, so that the database itself refuses a cross-tenant relation. Not supported in 1.0, which has single-column keys: `true` is refused by the mapping validator. Prism refuses cross-tenant relations at flush instead |

### `#[Timestampable]`

Sets the creation and update dates, in UTC. See [Audit and behaviors](/guide/audit#timestamps-and-authors).

| Parameter | Default | Description |
| --- | --- | --- |
| `createdAt` | `'createdAt'` | The mapped field set at `INSERT`, unless already set |
| `updatedAt` | `'updatedAt'` | The mapped field set when another field changes. `null`: never set |

### `#[Blameable]`

Sets the author of the creation and of the last update, from the `ActorProvider`.

| Parameter | Default | Description |
| --- | --- | --- |
| `createdBy` | `'createdBy'` | The mapped field set at `INSERT`, unless already set |
| `updatedBy` | `'updatedBy'` | The mapped field set when another field changes. `null`: never set |

### `#[SoftDeletable]`

Turns `remove()` into an `UPDATE` of the deletion date; deleted rows are left out of reads. See [Soft delete](/guide/audit#soft-delete).

| Parameter | Default | Description |
| --- | --- | --- |
| `field` | `'deletedAt'` | The mapped, nullable `\DateTimeImmutable` field that holds the deletion date |

### `#[Auditable]`

Writes each change of the entity into `prism_audit_log`, in the transaction of the flush. See [Audit log](/guide/audit#audit-log).

| Parameter | Default | Description |
| --- | --- | --- |
| `exclude` | `[]` | Fields left out of the changeset, `updatedAt` for example |
| `retention` | `null` | How long the rows are kept, as an ISO 8601 duration (`'P10Y'`), for `db:audit:purge`. `null`: purged only with `--older-than` |

## Symfony bundle

### `#[UniqueEntity]`

`Prism\Bundle\Validator\UniqueEntity`: a validation constraint, true when no other entity of the class has the same values. Class attribute, repeatable.

| Parameter | Default | Description |
| --- | --- | --- |
| `fields` | | A field or a `ToOne` relation, or a list of them checked together |
| `message` | `'This value is already used.'` | The violation message |
| `errorPath` | `null` | The property the violation is attached to. `null`: the first field |
| `ignoreNull` | `true` | A `null` value is never a duplicate, like in a database unique constraint |
| `entityManager` | `null` | The entity manager to query. `null`: the one that maps the class |
| `groups` | `null` | Validation groups |
| `payload` | `null` | Symfony's constraint payload |

### `#[AsPrismListener]`

`Prism\Bundle\Attribute\AsPrismListener`: listens to a Prism event (`PrePersistEvent`, `PostFlushEvent`...). On a class (its `__invoke()` method) or a method; repeatable.

| Parameter | Default | Description |
| --- | --- | --- |
| `event` | `null` | The event class. `null`: the type of the method's first parameter |
| `method` | `null` | On a class: the method to call. `null`: `__invoke` |
| `entityManager` | `null` | The entity manager whose events are listened to. `null`: all of them |
| `priority` | `0` | Higher priorities run first |

### `#[AsEntityListener]`

`Prism\Bundle\Attribute\AsEntityListener`: makes an entity listener, named in `#[EntityListeners]`, a service with its dependencies. Without it, the listener is created without arguments. No parameter.

### `#[AsEmbeddingProvider]`

`Prism\Bundle\Attribute\AsEmbeddingProvider`: registers an `EmbeddingProvider` service under a name, the one `#[EmbeddedVector(model:)]` gives. Without it, an autoconfigured provider is registered under its service id. See [Embeddings](/bundle/symfony#embeddings).

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | `'default'` | The name of the provider |

### `#[MapEntity]`

`Prism\Bundle\Attribute\MapEntity`: how a controller argument typed with an entity is loaded from the route. Without it, the identifier is the route parameter named after the argument, or `{id}`.

| Parameter | Default | Description |
| --- | --- | --- |
| `id` | `null` | The route parameter that holds the identifier |
| `mapping` | `null` | Route parameter → field, looked up with `findOneBy()`: `['number' => 'number']` |
| `entityManager` | `null` | The entity manager. `null`: the first one that maps the class |
| `disabled` | `false` | Leaves the argument to the other value resolvers |

## Migrations

### `#[IgnoreLint]`

`Prism\Migrations\Lint\IgnoreLint`: silences one linter rule for a migration. Class attribute, repeatable.

| Parameter | Default | Description |
| --- | --- | --- |
| `code` | | The rule, `'L12'` for example |
| `reason` | | Why the case is accepted; required, and shown by `db:migrations:lint` |

## Test pack

### `#[WithRealTransactions]`

`Prism\TestPack\Attribute\WithRealTransactions`: on a test class or method that uses `ResetDatabase`, disables the surrounding transaction: commits are real, and the schema is created again after the test. For a test that reads from another connection, or runs DDL under MySQL and MariaDB. No parameter.
